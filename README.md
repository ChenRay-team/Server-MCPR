# Server-MCPR 🎥

> **本仓库用于存放服务器玩家回放录像（.mcpr），方便玩家下载自己的录像。**
> ⚠️ **仅供学习与个人使用，禁止任何商业用途。**

---

## 📁 目录结构

```
Server-MCPR/
├── README.md        # 本说明
└── player/          # 玩家回放录像存放目录
    └── 玩家名/       # 每个玩家一个文件夹
        └── 2026-08-08@14-30-25.mcpr   # 录像文件
```

## 🎬 什么是 .mcpr？

`.mcpr` 是 [ReplayMod](https://github.com/ReplayMod/ReplayMod) 的回放录像格式，可以用 ReplayMod 客户端进行回放观看，查看自己/他人的游戏过程。

- **回放插件**：ISeeYou（由服务器自动录制玩家）
- **查看方式**：安装 ReplayMod 客户端 → 将 `.mcpr` 放入回放目录 → 游戏内回放

## 📥 如何下载自己的录像？

1. 进入 `player/` 目录
2. 找到**你自己的玩家名**文件夹（例如 `player/Steve/`）
3. 点击进入，下载里面的 `.mcpr` 文件
4. 用 ReplayMod 客户端回放观看

> 💡 录像文件较大（每个可能 2~50MB），请按需下载，不要批量拉取整个仓库。

## 📌 常见问题

**Q：为什么我找不到自己的文件夹？**
A：只有服务器录制过的玩家才会有文件夹；如果还没有，说明暂时没有录像记录。

**Q：录像会保留多久？**
A：取决于服务器设置（默认保留 7 天），建议及时下载保存。

**Q：可以在自己的视频里使用这些录像吗？**
A：可以用于个人学习、交流、非商业视频创作，但**禁止用于任何商业用途**（包括但不限于收费课程、商业推广、出售等）。
